# ShopSphere – Manual Testing Project

## Application Under Test
Practice Software Testing (Toolshop): https://practicesoftwaretesting.com/

## Objective
The objective of this project is to test the main features of an e-commerce website manually, identify issues if any, and document the testing results.

## Scope
This project covers the following five modules:
- Login and Registration
- Product Search
- Shopping Cart
- Coupon Application
- Checkout and Payment

Testing will be performed using dummy data. No real payment details or actual purchases will be used.

## Test Approach
I will understand the requirements, prepare test scenarios and test cases, and execute them manually. I will perform positive and negative testing, validation checks, and boundary testing wherever applicable. Any defects found during testing will be documented with steps to reproduce and supporting evidence.

## Test Environment
- Application: Practice Software Testing (Toolshop)

- Operating System: To be recorded during execution

## Deliverables
- Test-Scenarios.xlsx
- Test-Cases.xlsx
- Bug-Reports.xlsx
- Test-Execution-Report.md
- Screenshots/ (test evidence)

## Test Status
- **Pass:** The actual result matches the expected result.
- **Fail:** The actual result does not match the expected result.
- **Blocked:** The test could not be executed due to a limitation or dependency.
- **Not Run:** The test has not been executed yet.

## Note
Test results and bug reports will be based on actual execution. Only reproducible issues will be reported as defects.
